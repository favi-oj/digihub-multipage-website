# DigiHub Assignment 2.4
## Links, Paths and a Multi-Page Website

### Project Description

This project is a five-page website created using
HTML. It demonstrates how to connect webpages
using relative paths, absolute URLs, email links,
and fragment links.

### Website Pages

1. Home - index.html
2. About - about.html
3. Services - pages/services.html
4. Projects - projects.html
5. Contact - contact.html

### Link/Path Explanation Table

| Link Type | HTML Example | Explanation |
|---|---|---|
| Relative Link | `href="about.html"` | Opens the About page in the same folder. |
| Subfolder Relative Link | `href="pages/services.html"` | Opens the Services page inside the pages folder. |
| Parent Directory Link | `href="../index.html"` | Moves up one folder from pages and opens the homepage. |
| Absolute HTTPS Link | `href="https://developer.mozilla.org/en-US/docs/Web/HTML"` | Opens an external HTML documentation website. |
| Email Link | `href="mailto:favviigbins@gmail.com"` | Opens an email application with the recipient address. |
| Fragment Link | `href="#my-goals"` | Jumps to the My Goals section on the homepage. |

### Navigation Structure

All five webpages contain a navigation menu
created using the semantic HTML nav element.

The navigation menu allows visitors to move
between Home, About, Services, Projects,
and Contact pages.
